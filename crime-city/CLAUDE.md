# Crime City

Start with `AGENTS.md` and `docs/HANDOFF.md`. Follow the existing layout and user decisions documented there.

This is a portable local React/Vinext + Cloudflare Workers/D1 project. You do not need the original chat account to edit and run it locally. Install Node.js 24 LTS and project dependencies, then use either the fresh-database path or private-backup restore path in the handoff. Do not run both paths on the same database.

The original conversation is summarized in the handoff, not stored as a full chat export. Ask the user for the next change after reproducing the current UI. Do not independently complete placeholder features or redesign the app.
