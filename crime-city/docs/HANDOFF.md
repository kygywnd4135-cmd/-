# Crime City 인수인계

기준일: 2026-11-21 (한국 시간). 이 문서는 다른 AI, 다른 계정, 다른 PC에서 현재 프로젝트를 이어가기 위한 요약이다. 원래 대화 전체나 AI의 내부 상태를 복사한 것은 아니다.

## 1. 가장 먼저

1. `AGENTS.md`, 이 문서, `README.md`를 읽는다.
2. `docs/references/`의 사용자 와이어프레임과 `docs/screenshots/`의 최근 실제 화면을 확인한다. 공유용 소스 ZIP에는 계정 정보 노출을 막기 위해 화면 캡처가 포함되지 않으므로, 현지 스크린샷이 필요하면 원래 프로젝트에서 확인한다.
3. 화면을 바꾸기 전에 프로젝트를 실행해 현재 동작을 재현한다.
4. 사용자에게 다음 수정 요청을 받는다. 준비 중인 기능을 임의로 완성하거나 레이아웃을 재설계하지 않는다.

## 2. 제품과 현재 상태

- 이름: Crime City / 크라임 시티. 한국어 온라인 머더 미스터리 플랫폼.
- 흐름: 시작 화면 → 아이디 가입/로그인 → (신규) 암전 후 레이븐 스토리에서 닉네임 설정 → 로비 → 방 생성/입장 → 사건 플레이.
- 플레이 가능한 시나리오는 6인, 약 60분의 대학 캠퍼스 사건 `백야제: 일곱 번째 이름` 한 개다. 나머지 9개는 목록/소개만 있다.
- NPC 다섯 명과 혼자 체험할 수 있다. NPC 응답과 진행은 정해진 시나리오를 따른다. 외부 생성형 AI 연동은 없다.
- 코드와 정적 이미지는 소스 묶음에 포함된다. 계정/채팅/사진/방 기록은 별도의 비공개 SQL 백업에 포함된다.
- 아직 Git 저장소/원격 GitHub 연결은 없다. GitHub 저장소 생성이나 업로드를 한 것으로 간주하지 않는다.
- 기존 로컬 주소는 `http://127.0.0.1:5173/`이다. 다른 PC에서는 그 PC에서 서버를 실행해야 한다.

## 3. 디자인 결정: 반드시 유지

- 로비는 Frame 310의 B안만 사용한다. 1920 x 1080 원본 좌표와 비율을 유지하고 작은 창에서는 전체를 축소한다. 반응형으로 패널 순서를 바꾸지 않는다.
- 시작 화면은 2026-11-22 사용자 Figma `메인화면`(파일 WXE2oxQirLDJogRoFrdVGg, 노드 961:3)을 따른다. `app/CityStart.tsx`·`app/start.css`, 자산은 `public/assets/start/`. 로그인 전에는 회원가입 / 로그인 두 버튼(가운데 정렬, ←→·Enter)만, 로그인 후에는 Figma `메인화면2`(1098:79)대로 버튼 대신 '아무 키를 눌러 서버 입장'을 표시하고 아무 키나 클릭 시 글리치 효과 후 메인 로비로 들어간다. 로그아웃은 로비의 내 계정에서 한다. 공지·설정·친구와 함께하기·계정 카드는 제거했다. 배경 음악은 `public/audio/start-theme.mp3`(사용자 제공)를 시작 화면에서만 반복 재생하며, 우측 상단 스피커를 한 번 누르면 드래그 음량 슬라이더, 두 번 누르면 음소거다(기본 40%, 브라우저 정책상 첫 입력 뒤 재생). SEASON.01과 레벨업 제목은 빛의 계승자(네오플 무료 글꼴)를 쓰며, 설치된 글꼴이 없으면 `public/fonts/HeirofLight-*.woff2`를 내려받는다(출처: taedonn/fonts-archive 공개 저장소). 로비는 다크 모드만 제공한다.
- 일반 UI는 자체 제공 SUITE Variable을 사용한다. 빛의 계승자는 레벨업 제목과 숫자에 유지한다. 화이트 모드와 전환 버튼은 제거했다.
- 툴바: 사무소(임시 강조 버튼, `app/office.css`, 누르면 준비 중 안내. 사용자 디자인과 가챠 화면 Figma가 오면 교체) → 넓은 포인트 표시 → 폭죽 이벤트 → 친구 → 음량 → 설정 → 계정. 상점 아이콘과 프리머시 토큰 칸은 2026-11-22 삭제. 접속 인원 표시는 삭제했다.
- 내 정보 버튼: 내 프로필 설정 / 업적 확인하기 / 인벤토리 / 강조된 내 프로필 확대하기.
- 칭호는 내 정보 안에서 아래로 펼친 목록에서 즉시 선택한다. 자기소개는 해당 칸 우측 하단 연필로 직접 수정한다.
- 닉네임 UI는 Frame 333/334/340 계열이다. 안쪽 패널은 불투명하고, 가장 바깥 사각형의 내부 띠만 반투명이다. 창은 가로세로 정중앙이다.

### 최근 변경: 확대 프로필과 상대방 프로필

- `내 프로필 확대하기`는 Frame 345, 채팅 상대방 사진 클릭은 Frame 346을 따른다. 이전 작은 상대방 프로필 UI는 교체했다.
- 두 창은 `CityExpandedProfile.tsx`와 `expanded-profile.css`를 공유한다. `CityPublicProfile.tsx`는 상대방 모드로 호출하는 얇은 연결 컴포넌트다.
- 외곽 968 x 604, 안쪽 939 x 570. 원본 1920 x 1080을 기준으로 계산한다.
- 왼쪽 캐릭터 일러스트는 공백이다. PDF 속 여자 캐릭터는 임시 자료이므로 실제 앱에 넣지 않는다.
- 명예는 왼쪽 세로 그라데이션과 여섯 개 별로 표시한다. `last_game_honor`만 읽는다. 명예 투표/지급은 후속 작업이다.
- 레벨 아래 `Main : 미지정`은 폭 208, 높이 35의 가로 그라데이션 박스를 사용한다. 어두운 사선 배경과 같은 색으로 지워 보이게 하지 않는다.
- 확대창의 다크 팔레트는 검정보다 밝은 차콜이다. 2026-10-26 사용자 요청으로 **내 프로필 확대창은 로비 모드와 관계없이 이 다크 팔레트로 통일**했다. 이어서 상대방 프로필도 같은 다크 팔레트로 통일했다.
- 내 창: 스킨 변경은 비공개/비활성. 대표 업적 화살표로 소유 업적 목록을 열어 선택/저장한다. ESC는 열린 목록을 먼저 닫고 다음 ESC가 창을 닫는다.
- 상대방 창: 같은 위치에 `친구 요청하기`가 있으며 서버에 요청을 저장하고 성공/중복 안내를 표시한다. 상대방 대표 업적은 조회만 가능하며 펼침 화살표나 변경 동작이 없다. 파티 요청 버튼은 새 원본에 없으므로 표시하지 않는다.
- 두 창 모두 X/ESC/바깥 클릭 닫기, 포커스 복귀를 지원한다.

## 4. 계정과 프로필

- 로그인 아이디와 닉네임은 별개다. 아이디/비밀번호 가입 성공 후 첫 입장 스토리 안에서 레이븐이 이름을 물을 때 최초 닉네임을 설정한다.
- 닉네임: 한글/영문/숫자 2~12자, 공백/특수문자 불가. 정규화, 명시적 욕설/금칙어, 중복/현재 이름 검사. 서버에서도 같은 검증을 한다.
- 닉네임 설정/변경 후 7일 제한. 참여 중인 사건이 있으면 변경하지 못한다. 성공 시 `닉네임 변경 완료` 알림.
- 금칙어 검사는 명시적 목록이며 모든 변형을 자동 판별하는 완성형 시스템은 아니다. 기존 사용자의 데이터가 새 규칙과 다르더라도 QA 목적으로 고치지 않는다.
- 자기소개: 최대 180자, 줄바꿈, Ctrl+Enter 저장, ESC 취소. 칭호/자기소개 등 전용 저장은 다른 필드를 덮어쓰지 않는다.
- 프로필 이미지/테두리 탭: 각각 3열, 30칸, 내부 휠 스크롤. 사진 업로드는 정사각형으로 크롭 후 512px JPEG로 저장한다.
- 기본 이미지는 남자 A / 여자 A, 기본 테두리는 없음 / 붉은 크라임 시티. 나머지 칸은 미획득/잠금이다. 테두리 목록은 현재 사진에 각 테두리를 적용한 미리보기다.
- `profile_photos`의 사진은 DB 안의 data URL이다. `public/assets`만 옮겨서는 업로드한 사진이 복원되지 않는다.
- 기본 칭호는 뉴비 머미러 / 신중한 관찰자 / 밤의 기록자. 업적은 실제 종료한 방의 투표 기록으로 산출하며 대표 업적 하나만 저장한다.
- Google OAuth/PKCE/state 검증 준비는 되어 있으나 OAuth 프로젝트/비밀 설정은 아직 없다. 실제 로그인 연동 검증은 필요하다.

## 5. 준비 중인 기능

친구 목록/수락/거절 UI와 파티 기능, 게임 보상 포인트 적립 규칙, 이벤트 지급, 명예 투표, 지정 스킨, 독립 업적 확인 화면, 실제 스킨 일러스트/소비 아이템 게임 효과, 추가 9개 시나리오, 운영 도구, 계정 복구, 결제/음성 채팅. 자리표시 UI가 있다고 서버 기능까지 구현되었다고 주장하지 않는다.

## 6. 실행 환경과 새 PC 복원

Node.js 24 LTS와 npm을 권장한다. 패키지의 최소 Node 버전은 22.13이며 기존 검증은 Node 24에서 수행했다. PowerShell에서도 아래 npm 명령은 동일하다. 경로에 공백이 있으면 따옴표로 감싼다.

### 공통 준비

소스 ZIP 안의 `crime-city` 폴더를 원하는 위치에 풀고 그 폴더에서 실행한다.

```sh
npm ci
```

원본 PC의 `node_modules`, `.next`, `.vinext`, `dist`, `.sites-runtime`은 복사하지 않는다. 설치/빌드 시 다시 생성한다. `.sites-runtime/execution-profile.json`이 없으면 기존 스크립트가 portable 실행 모드를 선택한다.

### A. 기존 계정/사진/채팅까지 가져오기

비공개 데이터 ZIP을 소스 폴더 바깥에 풀고, 새 데이터베이스에 한 번만 복원한다.

```sh
npm run db:restore -- "C:/PrivateBackups/database.sql"
npm run db:check
npm run dev
```

위 경로는 예시이므로 실제 압축 해제한 SQL 파일 경로로 바꾼다. 복원에는 스키마까지 포함된다. 복원 전후에 `db:init` 또는 0000~0005를 다시 적용하면 안 된다. 복원 도구는 기존 앱 테이블이 있으면 중단한다. 기존 데이터를 덮어쓰거나 삭제하지 않는다.

### B. 실제 계정을 옮기지 않고 개발만 이어가기

데이터 백업을 다른 AI에게 줄 필요가 없다. 새 빈 DB를 만들고 테스트 계정을 가입한다.

```sh
npm run db:init
npm run dev
```

`db:init`은 현재 0000~0009 SQL을 이름 순으로 한 번씩 적용한다. 이미 데이터가 있으면 거부한다. A와 B 중 하나만 선택한다.

### 새 작업을 저장할 때

```sh
npm run db:export -- "C:/PrivateBackups/database-backup-새날짜.sql"
```

새 파일명만 허용한다. 출력 위치는 Git 프로젝트 바깥의 개인 백업 폴더로 지정한다. 로컬 `wrangler.local.json`은 Vite의 DB와 동일한 식별자/프로젝트 루트 상태 경로를 사용한다. `d1 export`에는 `--persist-to`가 없어서 `dist/server/wrangler.json`을 바로 사용하면 별도의 빈 DB를 읽을 수 있다. 이 문제를 피하도록 도구를 추가했다.

### 코드 검증

```sh
npm run check
npm run build
```

개발 서버가 실행 중일 때 관련 스모크 검증을 실행한다.

```sh
node scripts/public-profile-smoke.mjs
node scripts/expanded-profile-smoke.mjs
```

두 검증은 새 테스트 계정을 사용한다. 테스트 계정 데이터 일부가 DB에 남을 수 있다. 백업 시점 이후 원본 계정을 임의로 바꾸지 않는다.

## 7. 저장 위치와 이전의 한계

| 항목 | 위치/백업 | 다른 PC에서의 처리 |
| --- | --- | --- |
| 코드, 시나리오, 정적 로고/배경/기본 아바타/폰트 | 소스 ZIP / GitHub 후보 | 설치 후 그대로 사용 |
| 사용자, 암호 해시/솔트, 프로필, 업로드 사진, 채팅, 방/투표 기록 | 비공개 SQL ZIP | 별도 복원, GitHub/AI 채팅에 올리지 않음 |
| 테마/음량 | 브라우저 localStorage의 `crime-theme`, `crime-music`, `crime-effects` | 새 브라우저에서 다시 선택 |
| 개인 추리 수첩 | localStorage의 `noct-note-방ID-사용자ID` | SQL에 없음. 필요하면 원래 브라우저에서 별도로 복사 |
| 로그인 쿠키, 현재 열린 팝업/탭 | 기존 브라우저/메모리 | 쿠키를 공유하지 말고 다시 로그인, 창은 다시 열기 |
| 게임 타이머 | 서버 기록의 실제 시각 | 시간이 정지된 녹화가 아님. 복원 시 경과 시간에 따라 단계가 진행/종료될 수 있음 |
| Google OAuth 비밀/기타 환경변수 | 제외됨, 값은 채팅/문서에 저장하지 않음 | 필요할 때 안전한 런타임 비밀 설정으로 재등록 |
| 원래 AI 대화/계정 권한 | 소스에 자동 포함되지 않음 | 이 인수인계로 맥락 전달. 다른 AI가 이전 대화를 기억한다고 가정하지 않음 |

원본의 `.openai/hosting.json` 식별자는 기존 Sites 프로젝트 메타데이터다. 다른 계정의 배포 권한이나 인증이 전달되는 것은 아니다. 현재 공개 배포 URL은 이 인수인계에서 보장하지 않는다. 먼저 로컬에서 재현한 뒤 사용자가 선택한 배포 대상으로 별도 설정한다.

## 8. 주요 파일과 API

- `app/page.tsx`, `app/CrimeCity.tsx`: 진입, 시작 화면, B안 로비, 테마/음량, 채팅과 방 연결.
- `app/wireframe.css`, `lobby-themes.css`, `original-assets.css`: 위치와 색상/실제 자산. 여러 이전 CSS가 남아 있어 import 순서에 유의한다.

- 문서 §7의 미결 사항(플랫폼, 음성 방식, 수익 모델, AI 대타 방식·비용, 시나리오 공급, 보증금 재화)은 해당 기능을 만들 때 사용자에게 확인한다.
