# 백업 검증 결과

기준일: 2026-10-21 (한국 시간)

- 프로젝트 TypeScript 검사 통과.
- 프로덕션 빌드 통과.
- 현재 로컬 DB를 SQL로 내보냄.
- 별도 빈 로컬 D1 상태 폴더에 SQL 복원 성공.
- 9개 앱 테이블의 모든 열 정의와 모든 행을 비교했고, 정렬 후 SHA-256이 일치함. 업로드 사진 데이터도 포함함.
- SQL 재구성과 실제 복원 DB의 SQLite 무결성 검사 모두 ok.
- 별도 빈 DB에서 0000~0004 초기화 성공, 초기 데이터가 없는 것 확인.
- 데이터가 있는 DB에 초기화/복원을 시도하면 거부하는 것 확인.
- 이미 있는 SQL 백업으로 내보내기를 시도하면 거부하며 원본 바이트가 유지됨.
- 복원 경로 누락을 거부하는 것 확인.
- 소스 ZIP에서 실행 상태/데이터/비밀 설정을 제외하고 필요한 코드/자산/문서/마이그레이션을 포함했는지 검사.
- 두 ZIP의 CRC 검사 및 소스 파일별 SHA-256 일치 확인.

DB 복원 시험은 현재 PC의 Node.js 24.19.0과 설치된 Wrangler 4.92.0을 재사용하고, DB 설정과 상태는 분리한 시험 폴더에서 실행함. 새 PC의 npm ci를 실제로 수행한 검증은 아님. 원래 브라우저 상태나 OAuth 비밀, 외부 계정 권한은 백업에 포함되지 않음. 예약/자동 백업은 설정하지 않음. GitHub 계정 연결이나 업로드는 하지 않음.
