# 크라임 시티 백업 사용 순서

이 묶음은 2026-10-21 한국 시간의 로컬 프로젝트를 다른 계정/AI/PC에서 이어가기 위한 백업입니다. GitHub 업로드나 계정 연결은 하지 않았습니다.

## 1단계: 두 ZIP을 구분해 보관하세요

- `crime-city-source-2026-10-21.zip`: 코드, 시나리오, 로고/배경/기본 프로필/폰트, 사용자 원본 와이어프레임, 최근 화면, 인수인계 문서. 다른 개발 AI에게 넘길 기본 파일입니다.
- `crime-city-private-data-2026-10-21.zip`: 기존 계정, 암호 해시/솔트, 채팅, 업로드한 사진, 방/게임 기록, 세션이 들어 있는 SQL 백업입니다. GitHub나 AI 채팅에 올리지 말고 본인 저장소/외장 장치에 따로 보관하세요. ZIP 자체는 암호화하지 않았습니다.
- `BACKUP-MANIFEST.json`, `VERIFICATION.md`: 파일 무결성과 복원 검증 기록입니다.

두 ZIP을 이 PC와 별도로 외장 SSD 등 다른 저장장치에도 한 번 더 복사해 두세요. 코드는 GitHub에 보관해도 데이터 백업까지 자동으로 올라가는 것은 아닙니다.

## 2단계: 가장 간단하게 다른 AI에서 이어가기

1. 소스 ZIP을 압축 해제합니다. 안의 `crime-city` 폴더가 프로젝트입니다.
2. 다른 AI의 로컬 개발 도구에서 이 폴더를 엽니다. 예: Claude Code 등 로컬 파일을 편집/실행할 수 있는 도구.
3. 아래 인수인계 문장을 첫 메시지로 보냅니다.
4. 새 테스트 계정으로 작업하면 비공개 데이터 ZIP을 AI에게 전달할 필요가 없습니다.

> 이 프로젝트는 온라인 머더 미스터리 플랫폼 크라임 시티입니다. 현재 구현을 이어가고 싶습니다. 먼저 AGENTS.md, CLAUDE.md, docs/HANDOFF.md를 읽고, docs/references의 원본과 docs/screenshots의 최신 화면을 확인해 주세요. 처음부터 다시 만들거나 레이아웃을 임의로 바꾸지 마세요. 실행 방법에 따라 현재 화면을 재현한 뒤 제가 요청하는 부분만 수정해 주세요. 실제 계정이 든 비공개 데이터 ZIP은 코드와 별도입니다.

일반 채팅 화면에 GitHub 주소나 ZIP을 전달한 것만으로 로컬 폴더 수정/서버 실행까지 되는 것은 아닙니다. 사용하는 AI 도구가 파일과 터미널에 접근할 수 있어야 합니다. 접근할 수 없다면 문서/코드 검토부터 하거나 로컬 개발 도구를 이용하세요.

## 3단계: 새 PC에서 화면 실행하기

1. 공식 Node.js 사이트에서 Node.js 24 LTS를 설치합니다: https://nodejs.org/
2. 소스 ZIP을 풀어 `crime-city` 폴더를 엽니다.
3. 이 폴더에서 터미널을 열고 아래 명령을 한 줄씩 실행합니다.

```sh
npm ci
npm run db:init
npm run dev
```

4. 브라우저에서 `http://127.0.0.1:5173/`을 엽니다.
5. 새 테스트 계정을 가입하고 로비를 확인합니다.

이는 코드와 화면을 이어가는 방법입니다. 기존 실제 계정과 사진까지 필요한 경우에는 다음 단계로 진행하고 `db:init`을 먼저 실행하지 마세요.

## 4단계: 기존 계정/사진/채팅까지 복원하기

1. 소스를 새 폴더에 풉니다. 이미 테스트 DB를 만든 폴더는 그대로 보관하고 별도 새 폴더를 사용하세요.
2. 데이터 ZIP은 소스 폴더 바깥의 개인 백업 폴더에 풉니다.
3. 소스 폴더의 터미널에서 실행합니다. SQL 경로는 실제 압축을 푼 경로로 바꾸세요.

```sh
npm ci
npm run db:restore -- "C:/PrivateBackups/private/database.sql"
npm run db:check
npm run dev
```

4. 기존 아이디/비밀번호로 다시 로그인합니다. 새 브라우저로 로그인 쿠키까지 자동 이전되지는 않습니다.
5. 닉네임, 프로필 사진/테두리, 자기소개, 채팅을 확인합니다.

복원 도구는 기존 앱 테이블이 있으면 중단합니다. 초기화와 복원을 같은 DB에 모두 실행하지 않습니다. 이미 데이터가 있는 원본 프로젝트에 백업을 덮어쓰지 마세요.

테마와 음량은 새 브라우저에서 다시 선택하면 됩니다. 개인 추리 수첩은 원래 브라우저 안에만 저장되어 SQL에는 없습니다. 필요한 수첩이 있다면 원래 화면에서 내용을 따로 복사해 보관하세요. 게임의 실제 타이머는 정지된 스냅샷처럼 재개되지 않을 수 있습니다. 전체 AI 대화 기억과 외부 계정 권한은 이 백업으로 자동 이전되지 않습니다.

## 5단계: 본인 GitHub에 비공개 저장소로 보관하기

현재 백업은 어떤 GitHub 계정에도 올리지 않았습니다. 아래 과정을 할 때 사용할 본인 계정부터 확인하세요.

1. 공식 GitHub Desktop을 설치하고 본인 GitHub 계정으로 로그인합니다: https://desktop.github.com/
2. 소스 ZIP을 풀어 `crime-city` 폴더를 준비합니다. 비공개 데이터 ZIP/SQL은 이 폴더 바깥에 둡니다.
3. GitHub Desktop에서 `File → Add local repository`로 `crime-city` 폴더를 선택합니다.
4. 아직 Git 저장소가 아니라는 안내가 나오면 해당 위치에 저장소를 만드는 `create a repository`를 선택합니다. 기존 파일은 그대로 사용하고 라이선스/다른 템플릿을 임의로 덮어쓰지 마세요.
5. 변경 파일 목록을 살펴보고 `.env`, `.dev.vars`, `.wrangler`, `node_modules`, 실제 데이터 SQL/ZIP이 포함되지 않았는지 확인합니다. `drizzle/` 안의 0000~0004 SQL은 필요한 구조 변경 파일이므로 포함합니다.
6. 첫 저장 설명을 `현재 크라임 시티 백업`으로 적고 `Commit to main`을 누릅니다. 현재 브랜치 이름이 다르면 그 브랜치에 저장합니다.
7. `Publish repository`를 누릅니다. 이름은 예를 들어 `crime-city`로 하고 **Keep this code private를 체크한 채로** 게시합니다.
8. 표시되는 소유 계정이 본인 계정인지 확인한 후 게시합니다.
9. GitHub 웹에서 코드와 `docs/HANDOFF.md`가 올라갔는지 확인합니다.

GitHub Desktop의 공식 안내: https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-an-existing-project-to-github-using-github-desktop

다른 AI나 다른 PC에서 비공개 저장소에 접근하려면 그 도구/계정에 접근 권한이 있어야 합니다. 저장소를 공개로 바꾸거나 비밀번호/토큰을 채팅에 보낼 필요는 없습니다. 어려우면 소스 ZIP을 로컬 개발 도구로 여는 방법부터 사용하세요.

## 6단계: 앞으로 작업할 때마다 저장하기

- 코드/이미지/문서를 수정한 뒤 GitHub Desktop에서 변경 내용을 확인하고 Commit, Push origin을 실행합니다.
- 실제 계정/채팅/업로드 사진도 보존하려면 SQL을 새 파일명으로 따로 백업합니다.

```sh
npm run db:export -- "C:/PrivateBackups/database-backup-새날짜.sql"
```

- 다음 AI가 쉽게 이어가도록 `docs/HANDOFF.md`의 최근 변경사항도 갱신합니다.
- 이 백업은 기준 시점의 복사본입니다. 앞으로의 수정사항을 자동으로 보관하는 예약 백업은 설정하지 않았습니다.
- Google 로그인 비밀/새 배포 설정은 포함되지 않았습니다. 로컬 실행을 확인한 다음 필요할 때 따로 설정합니다.
