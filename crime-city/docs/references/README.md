# 사용자 원본 자료

사용자가 제공한 이미지를 수정하지 않고 보관했다. 파일마다 시점이 다르므로 최신 지시가 우선이다.

| 파일 | 의미 | 현재 적용 |
| --- | --- | --- |
| Frame 306.png | 시작 화면 | 로고/배경은 public/assets의 실제 제공 이미지 사용 |
| Frame 309.png | 이전 A안 로비 | 과거 자료. 이 로비로 되돌리지 않음 |
| Frame 310.png | B안 로비 | 현재 채택한 고정 배치 |
| Frame 333.png / 334.png / 340.png | 닉네임 창과 오류 창 | 다크/화이트 테마, 바깥 띠만 반투명 |
| Frame 337.png | 이전 상대방 프로필 | 과거 자료. 현재는 Frame 346으로 교체됨 |
| Frame 338.png / 339.png | 이미지/테두리 선택 | 각 탭 3열 30칸. 실제 획득 제한은 사용자 지시가 우선 |
| Frame 345.pdf | 내 확대 프로필 | 현재 배치 기준. 캐릭터 여자 일러스트는 사용하지 않음 |
| Frame 346.pdf | 상대방 확대 프로필 | 내 창과 같은 배치, 친구 요청/읽기 전용 대표 업적으로 차이 |

회색 원본은 레이아웃 와이어프레임이다. 실제 색상은 현재 다크/화이트 모드 구현과 최근 스크린샷을 따른다. 원본의 임시 텍스트/그림/가상의 수치를 실제 사용자 데이터나 구현된 기능으로 간주하지 않는다.
