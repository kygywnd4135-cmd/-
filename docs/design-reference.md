# 제디스4 UI 디자인 레퍼런스

> 참고 출처: Geex Arts의 Dribbble 시안 5장 (AI OS / Music OS / Board / Bezy / Favorites)
> 원본 이미지를 그대로 베끼는 게 아니라, **디자인 언어(원칙)** 만 뽑아서 정리한 문서.
> 이후 UI 작업은 이 문서를 기준으로 한다.

---

## 1. 한 줄 요약

**"스위스 타이포그래피 + 아날로그 하드웨어 감성 + 모눈종이 그리드"**
무채색 바탕 위에 검정 덩어리(노브, 원형 버튼, 큰 숫자)를 박고, 포인트 컬러는 아주 조금만 쓴다.

---

## 2. 핵심 패턴

### 2-1. 폴더 탭 스택 (AI OS 시안) ← 이번 "탭"의 핵심
- 서류철 인덱스 탭처럼 **여러 장이 겹쳐 쌓인 형태**.
- 탭 모양: 왼쪽은 둥근 모서리, **오른쪽 끝은 사선(경사)으로 깎임**.
- 탭마다 왼쪽에 **번호 원형 배지** (`09`, `23`, `31`, `51`, `91`...) — 연한 원 안에 굵은 숫자.
- 라벨은 **투톤**: 앞 단어는 검정 Bold, 뒷 단어는 연회색.
  - 예: **Style** Rolls / **Music** Wave / **Menu** Planning
- 탭 색이 다 다름: 주황, 올리브, 검정, 연회색, 세이지 그린, 흰색 → 각 탭 = 각 카테고리.
- 뒤에 있는 탭일수록 위쪽·뒤쪽에 깔리고, 맨 앞 탭(흰색)이 본문 패널과 이어짐.

### 2-2. 모눈종이 그리드 배경
- 아주 얇은 회색 격자 + **일부 칸만 살짝 진하게 채움** (픽셀 패턴처럼).
- 요소들이 격자 칸에 딱 맞춰 배치됨 → 정돈된 "설계도" 느낌.

### 2-3. 하드웨어 컨트롤
- **검정 원형 노브**: 흰 눈금 선 2개로 회전 각도 표시.
- 노브 옆 **상태 점**: 빨강 / 노랑 / 초록 (작은 원).
- **릴 테이프**(Music OS): 연한 원판 + 검정 3갈래 허브, 재생 시 회전.
- **조그 휠**: 큰 검정 도넛 + 흰 눈금.
- 파형(waveform): 재생된 부분 검정, 남은 부분 연회색, 구간 선택 브래킷.

### 2-4. 원형 버튼
- 검정 원 + 흰 화살표(↗, →, ↓), 검정 원 + 흰 숫자(`2`).
- 흰 원 + 검정 숫자를 검정 사각 테두리로 감싼 변형(`5`).
- 컬러 원 버튼: 핑크 `2`, 주황 `↗`, 초록 `↘`, 노랑 `1` — 크게, 꽉 찬 색.
- FAB: 우하단 큰 검정 원 (검색 등).

### 2-5. 카드
- 흰 카드 + 부드러운 그림자, 둥근 모서리(≈24px).
- 카드 여러 장이 뒤로 겹쳐 쌓인 스택 표현 (Board).
- Favorites: 카드/스티커가 **살짝 기울어져(rotate)** 흩어진 콜라주 레이아웃.
- 알약형 라벨(흰 pill에 텍스트), 핑크 가격 태그, 형광 노랑 카드.
- `ON` 토글 = 검정 원 안의 흰 글씨.

### 2-6. 숫자 & 타이포
- **거대한 숫자**가 주인공: `284` Files, `F4`, `09:56`, `68%`.
- 숫자 옆에 아주 작은 회색 단위/설명(`Files`, `%`).
- **도트 매트릭스 숫자/글씨**: `92`, `3,5M`, `Easy Breezy` — LED 전광판 느낌.
- 제목도 투톤 2줄: **Top** / Product(회색), **The Best** / Categories(회색).
- 메타 정보: `{002}`, `01 Jan – 29 Des` 같은 작은 인덱스·날짜.

### 2-7. 모션 (영상 시안 기반 추정)
- 탭 클릭 → 해당 탭이 앞으로 슬라이드.
- 노브/릴 회전, 파형 스크럽.
- 진행 바에 **블러 글로우**(핑크가 번지는 느낌).

## 3. 디자인 토큰 (초안)

```css
:root {
  /* 바탕 */
  --bg:          #EDEDED;  /* 기본 연회색 */
  --surface:     #FFFFFF;
  --grid-line:   #DCDCDC;
  --grid-fill:   #E3E3E3;
  --warm:        #D9CBC3;  /* Music OS 베이지 */
  --khaki:       #C9C3A9;  /* Bezy 카키 */
  --charcoal:    #2E2E2E;
  --ink:         #0A0A0A;  /* 검정 덩어리 */
  --muted:       #9A9A9A;  /* 투톤 라벨 뒷단어 */

  /* 탭 카테고리 색 */
  --tab-orange:  #FFB547;
  --tab-olive:   #A3A385;
  --tab-sage:    #A9B8AE;
  --tab-grey:    #CFCFCF;

  /* 포인트 (조금만!) */
  --pink:        #FF7AB8;
  --red-orange:  #FF5A36;
  --green:       #12B850;
  --yellow:      #FFD400;
  --neon:        #E8F000;
  --dot-red:     #E8231B;

  --radius-card: 24px;
  --radius-tab:  16px;
}
```

폰트 후보: **Inter / Helvetica Now / Neue Haas** 계열 (본문·제목),
도트 숫자는 **Doto**(Google Fonts) 같은 도트 폰트나 직접 SVG로.

## 4. 냉정한 평가 — 그대로 쓰면 안 되는 부분

1. **회색 뒷단어 대비가 너무 약함.** `Rolls`, `Product` 같은 연회색 글씨는 흰 배경에서
   대비 2:1 수준이라 실제 정보로 쓰면 안 읽힘. 장식용일 때만 쓰고, 중요한 정보면 대비 4.5:1 이상으로.
2. **탭 8개 겹치기는 폰에서 못 씀.** 시안은 폴더블 펼친 화면(가로 넓음) 기준이라 가능한 것.
   폰 폭(≈390px)에선 탭 4~5개가 한계 → 나머지는 가로 스크롤이나 "더보기"로.
3. **겹친 탭은 터치 영역이 작음.** 뒤에 깔린 탭은 보이는 부분이 좁아서 잘못 누르기 쉬움.
   최소 44px 터치 영역 확보 필요.
4. **노브는 터치 입력으로 별로임.** 손가락으로 돌리는 건 정밀도가 낮음.
   보여주기용 + 탭/드래그 시 슬라이더로 대체하는 방식 추천.
5. **Dribbble 시안은 "멋"이 우선이라 기능이 비어 있음.** `Create Button Place` 같은 더미 문구가 그대로임.
   실제로 만들 땐 각 탭/카드가 **무슨 기능인지 먼저 정하고** 스타일을 입혀야 함.
6. 미니언 같은 **남의 캐릭터·브랜드 에셋은 쓰지 말 것** (저작권).

## 5. 적용 원칙 (체크리스트)

- [ ] 바탕은 무채색, 포인트 컬러는 화면당 1~2개
- [ ] 검정 덩어리(원 버튼/노브/큰 숫자)로 시선 고정
- [ ] 라벨은 투톤 (Bold 검정 + 회색), 단 정보성 텍스트는 대비 확보
- [ ] 번호 배지로 항목에 인덱스 부여
- [ ] 모눈 그리드 위에 정렬
- [ ] 숫자는 크게, 단위는 작게
- [ ] 모바일에서 탭 수·터치 영역 검증
