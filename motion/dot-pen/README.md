# 도트 펜 모션 (메모칸 → 본체)

메모칸에서 본체로 정보가 옮겨가는 연결(펜로딩) 모션.
도트 매트릭스 위에 붓 획이 하프톤으로 그려지며 위→아래로 내려온다.

- 길이 4.2초, 루프
- 메모칸 639×252 + 본체 639×750을 한 캔버스(639×1002)로 계산 후 분할
- 도트 간격 12px (252가 12의 배수라 이음새에서 그리드가 맞물림)
- 본체 기준 y≈210부터 페이드, y≈270 이후는 완전히 꺼짐 → 본체 중간 텍스트 영역 보호

| 파일 | 용도 |
|---|---|
| `memo-rotated-for-figma.gif` | 피그마 `메모칸 - 펜로딩` 프레임용 (프레임이 90° 회전돼 있어서 시계방향 90° 돌려둔 것) |
| `memo.gif`, `body.gif` | 정방향 원본 |
| `preview.mp4`, `preview.gif` | 두 화면 사이 이음새를 넣은 확인용 |

다시 만들기:

```bash
python3 gen.py frames
```
